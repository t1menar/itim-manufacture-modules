| `admin-api/admin-api.docx` | Authentication, roles, administrative API (Go) |
| `admin-panel/admin-panel.docx` | Web client screens and behaviour (React + TypeScript) |
| `module-video/module-video.docx` | Video creation, localization, quality checks, prompts for Claude Code (Python) |
| `module-review/module-review.docx` | Telegram review bot (Python) |
| `module-publish/module-publish.docx` | Publishing to Instagram Reels and future platforms (Python) |

Each folder has the same name as the service repository in `~/projects/manufacture/`.
